# Description
This project replicates the metrics generated by Sapena et al. (2020) using Python 3.x codes integrated with ArcGIS Pro functions.

Sapena et al. (2020) conducted the analysis writing Python 2.x code integrated with ArcMap functions and the ArcMap toolkit IndiFrag. The codes and part of the data are included in a replication package available at https://doi.org/10.6084/m9.figshare.12554531.v1. The built-up raster (GHS-BUILT R2018A) is available to download from https://data.jrc.ec.europa.eu/dataset/jrc-ghsl-10007.

# Reference
Sapena, Marta, Luis Ruiz, and Hannes Taubenböck. “Analyzing Links between Spatio-Temporal Metrics of Built-Up Areas and Socio-Economic Indicators on a Semi-Global Scale.” ISPRS International Journal of Geo-Information 9, no. 7 (July 11, 2020): 436. https://doi.org/10.3390/ijgi9070436.
